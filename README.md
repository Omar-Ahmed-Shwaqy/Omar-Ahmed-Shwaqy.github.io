# Omar Ahmed Shawky — GitHub Pages Portfolio

Static portfolio website for `Omar-Ahmed-Shwaqy.github.io`.

## Deploy
1. Upload these files to the repository `Omar-Ahmed-Shwaqy.github.io`.
2. In GitHub: Settings → Pages.
3. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save and wait for GitHub Pages to publish.

The site is fully static and needs no build step.
